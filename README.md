# Hello App

Introductory React application created with Create React App.

## Components

- `Message` is a function component. The text is passed through the `message` prop. The prop has a default value and is required.
- `Power` calculates x raised to the power of y from two number inputs.
- `Complex` calculates the modulus or the inverse of a complex number entered as `a+jb` or `a+ib`.
